# Security

If you discover a security problem in this project, please do not publish credentials,
tokens, personal data, or exploit details in a public issue.

Report the problem privately to the repository owner through GitHub.

Security rules for this project:
- Never commit passwords, API keys, private keys, access tokens, or service-role keys.
- Treat all user-provided data as untrusted input.
- Do not execute user-provided HTML, JavaScript, or URLs without strict validation.
- Keep authentication secrets and administrative credentials outside static client code.
- Review dependency and GitHub Actions updates before accepting them.
